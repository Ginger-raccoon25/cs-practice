рабочая папка- папка на компе, в которой находятся файлы проекта
Индекс- это черновик следующего коммита
Коммит- это фиксирование прокта в памяти в определенном состоянии, к которому можно вернуться
Git- это инструмент, с помощью которого можно отслеживать изменения в коде проекта, запоминать их, и возвращаться к их предыдущим версиям, а Githab это онлайн платформа, на основе Git, в которую можно загружать и выгружить файлы. Также загруженные файлы становятся доступны другим.
git abb- добавляет новые или изменённые файлы
git diff- команда выводит изменения, которые внесли в файлы, но ещё не добавили в индекс с помощью git add
git diff --staged- сравнивает индекс и последний коммит, демонстрирует изменения, которые уже добавлены в индекс и поэтому готовы к коммиту
"ветка"- это указатель (ссылка) на конкретный коммит в истории проекта.
